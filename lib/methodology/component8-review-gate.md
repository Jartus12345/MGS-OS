# MGS Human Review Gate v1.0

AI does not make the final strategic decision. Before anything is client-ready, MGS must review:

- EVIDENCE — can every significant claim be defended?
- REASONING — do conclusions logically follow from evidence?
- CONTRADICTIONS — have difficult or conflicting findings been properly handled?
- SPECIFICITY — could this reasonably have been written for another company?
- COMMERCIAL RELEVANCE — does the strategy genuinely support leadership's objectives?
- HUMANITY — does this sound like MGS rather than generated consultancy copy?
- RESTRAINT — has anything been overstated?
- USEFULNESS — can this strategy genuinely guide the next 12 months?
- CLIENT SENSITIVITY — are difficult findings expressed appropriately without avoiding them?

MGS then chooses one of: Approve Internally / Edit / Return to Analysis / Request Additional Evidence / Request Client Clarification / Flag Strategic Judgement Required.

Nothing produced by the application is automatically labelled "final." The pipeline always terminates in status: AWAITING MGS HUMAN REVIEW.
